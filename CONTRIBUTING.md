# Contributing

## Branches

- `main` should stay stable.
- Use feature branches for work in progress, for example `feat/player-movement` or `fix/audio-loop`.
- Prefer pull requests before merging larger changes.

## Before pushing

- Pull the latest `main`.
- Make sure the project opens locally.
- Keep generated cache/build files out of commits.
- Put large binary assets in formats already covered by Git LFS.

## Commit style

Use short, clear messages:

- `feat: add player dash`
- `fix: correct camera bounds`
- `art: add prototype tileset`
- `audio: add menu theme`
- `docs: update setup notes`
