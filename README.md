# GMTK2026_RAC

Game project repository for GMTK 2026.

## Setup

1. Install Git and Git LFS.
2. Clone the repository:

   ```bash
   git clone https://github.com/Liangzhenkun/GMTK2026_RAC.git
   ```

3. Enter the project folder and pull LFS assets:

   ```bash
   cd GMTK2026_RAC
   git lfs pull
   ```

4. Open the project with the game engine selected by the team.

## Collaboration

- Work on branches instead of committing directly to `main`.
- Open a pull request for review when a feature or fix is ready.
- Avoid committing local cache, temporary files, build outputs, or exported packages.
- Store art, audio, video, and other large binary assets through Git LFS.

## Repository Notes

The repository is currently public. Anyone can view and fork it, but only people with write permission can push branches directly to this repository.
